# Project Screenshots

This directory is reserved for approved screenshots of the YuHome platform.

Recommended screenshots for the public case study:

1. Home page
2. Property listing or accommodation view
3. Property detail page
4. Reservation flow
5. Responsive / mobile view
6. Administrative dashboard, only if approved for public disclosure

```text
01-home.png
02-properties.png
03-property-details.png
```

Only screenshots that do not expose personal data, credentials, confidential commercial information or sensitive administrative data should be published.
